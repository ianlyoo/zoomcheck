      ZoomCheck 시작 안내

      1 / 6
      01회의 준비
      시작 전에

      회의 ID와 권한을 확인하세요

      Zoom 회의에는 호스트 또는 공동호스트로 들어가고, ZoomCheck 상단에 회의 ID를 입력합니다. 숫자 사이 공백은 자동으로 정리됩니다.

      • 회의를 진행하는 PC와 ZoomCheck PC가 달라도 됩니다.
      • Pro 계정은 회의 안의 ZoomCheck 앱으로 참가자를 가져옵니다.
      02Excel 명단
      설정 → Excel 명단

      출석 명단을 올리세요

      번호·성명 열이 있는 Excel 파일을 선택하고 명단 올리기를 누릅니다. 기존 입퇴장 기록은 같은 명단을 다시 올려도 유지됩니다.

      • 전화번호·이메일·소속기관 열도 참가자 상세와 검색에 사용됩니다.
      • 조별 실습은 조·분반·그룹·팀·반 열 중 하나를 추가하세요.
      03Zoom 연결
      설정 → Zoom 앱 (Pro) 페어링

      6자리 코드로 회의와 연결하세요

      페어링 코드 생성을 누른 뒤, Zoom 회의의 Apps → ZoomCheck에서 코드를 입력합니다.

      1. 연결 방식은 자동을 권장합니다.
      2. 코드는 10분·1회용이며 연결 후에는 코드 만료와 무관하게 세션이 유지됩니다.
      3. Zoom 앱 상태가 호스트 연결 또는 공동호스트 연결인지 확인합니다.
      04실시간 동기화
      대시보드 상단

      지금 동기화를 눌러 출석을 시작하세요

      처음에는 지금 동기화를 눌러 명단과 현재 참가자가 맞는지 확인합니다. 이후 자동 동기화를 켜면 기본 10초마다 갱신됩니다.

      • 회의 ID가 비어 있으면 연결된 Zoom 회의 ID를 자동으로 가져옵니다.
      • Zoom 앱에서 “암호화 전송”이 보이면 참가자 정보가 PC로 안전하게 전달되는 중입니다.
      05결과 확인
      참가자 · 최근 활동 · 중복 연결

      검토가 필요한 사람을 확인하세요

      참가자 행을 누르면 원래 Zoom 이름, 전화번호, 조, 입퇴장 이력을 볼 수 있습니다. 이름이 명단과 확실히 일치할 때만 실제 Zoom 이름 변경 버튼이 나타납니다.

      • 검토와 미매칭 탭은 사람이 한 번 확인하세요.
      • 최근 활동에는 입장·퇴장·이름 변경, 중복 연결에는 다중 기기 접속이 표시됩니다.
      06마무리
      조별 확인 · CSV · 업데이트

      필요한 범위만 확인하고 저장하세요

      그룹 선택에서 특정 조를 고르면 그 조의 출석 현황과 CSV만 확인할 수 있습니다. 회의가 끝나면 CSV 내보내기로 결과를 저장하세요.

      • 출석 DB는 이 PC의 로컬 폴더에 저장됩니다.
      • 새 버전은 자동으로 확인·검증하며, 설치는 직접 누를 때만 진행됩니다.
      • 이 안내는 상단 사용법 또는 설정에서 언제든 다시 열 수 있습니다.
