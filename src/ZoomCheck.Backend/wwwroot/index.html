2. Zoom API 실시간 동기화

Server-to-Server OAuth 연결

Zoom 계정 관리자가 만든 앱의 Account ID, Client ID, Client Secret과 dashboard:read:list_meeting_participants:admin 권한이 필요합니다. 기존 classic 앱은 dashboard_meetings:read:admin을 사용합니다. 공동호스트 권한만으로는 API가 열리지 않습니다.

실시간 동기화 꺼짐

Zoom이 일시적으로 빈 목록을 보내도 기존 출석은 자동으로 보존됩니다. 회의가 실제로 끝나 0명이 맞을 때만 위 옵션을 체크한 뒤 [지금 참가자 불러오기]를 누르세요. 자동 동기화에는 적용되지 않습니다.

백업 · 참가자 목록 직접 붙여넣기

API를 쓸 수 없을 때만, 반드시 <전체> 목록을 붙여넣으세요

붙여넣은 목록은 지금 이 순간 회의에 있는 사람 전체로 처리됩니다. 목록에 없는 사람은 모두 퇴장으로 기록됩니다. Zoom 참가자 패널을 끝까지 스크롤해 전원을 선택·복사한 뒤 붙여넣으세요. 일부만 붙여넣으면 출석 기록이 잘못됩니다.

빈 줄과 중복 이름은 자동으로 무시됩니다. 최대 2000명까지 보낼 수 있습니다.
