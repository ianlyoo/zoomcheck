# ZoomCheck 0.6.2 업데이트

2026-09-08 · v0.6.2 · 기존 오류 수정과 UX 개선 포함

## 불참자를 오늘 명단에서 제외하기

1. 대시보드에서 참가자 이름을 눌러 상세를 엽니다.
2. **오늘 명단에서 제외 (불참)** 를 누르고 대상·날짜를 확인합니다.
3. **확인하고 적용** 을 누르면 오늘 출석률의 분모, 미참석·검토 집계, 기본 명단, CSV에서 제외됩니다.
4. 다시 포함하려면 **제외됨 → 참가자 이름 → 오늘 명단에 복원** 을 선택합니다.

원본 Excel 명단과 과거 입퇴장 기록은 보존됩니다. 제외는 **회의 ID + 서버를 실행하는 PC의 현지 날짜**에 적용되며, 다음 날짜에는 다시 포함됩니다. 앱 재시작이나 같은 명단 재업로드 후에도 당일 제외가 유지됩니다. 연결 중인 사람을 제외해도 실제 Zoom 연결을 끊지는 않습니다. 모든 사람을 제외한 경우에도 0명 집계와 CSV가 정상 동작합니다.

## 함께 반영한 개선

- **검토 완료 동선:** 이름 일치 등 신원 검토와 중복 기기 검토를 각각 확인·보류·취소할 수 있습니다. 보류는 검토 목록에 남습니다. 판단 근거가 달라지면 이전 확인을 그대로 적용하지 않습니다.
- **미매칭 처리:** `iPad` 같은 표시 이름을 상세에서 검색한 명단 인물과 연결하거나 취소할 수 있습니다. 이 회의의 해당 연결에만 적용되며 영구 별명을 만들지 않습니다. 재입장·이름 변경 이후에도 이전 연결의 출석 근거를 보존합니다.
- **집계 기준 표시:** 명단 참석 인원, 미매칭 이름 개수, 기기 연결 건수를 구분했습니다. 같은 미매칭 이름의 여러 연결은 이름 한 행 아래에서 확인합니다.
- **수신 상태 표시:** 화면 조회 시각과 실제 참가자 목록 수신 시각을 나눴습니다. 요청 접수나 오류를 새 참가자 수신으로 표시하지 않습니다.
- **회의 준비:** 명단·회의 ID·참가자 수신 상태에 따라 다음 행동을 안내하고, 설정에서 명단과 회의 준비를 먼저 배치했습니다.
- **직접 입력:** 전체 목록임을 확인한 뒤 반영하며, 입력 줄·서로 다른 이름·중복 줄과 처리된 입장·퇴장·제외 내역을 보여 줍니다.
- **CSV 범위:** 버튼에 대상 인원수를 표시합니다. 선택한 그룹과 오늘 제외 상태를 반영하며, 검색·상태 필터와 미매칭 항목은 내보내기에 포함하지 않는다는 설명을 표시합니다. 신원·중복 검토 상태 열도 추가했습니다.
- **화면 개선:** 기존 화면 구성을 유지하면서 다크모드의 푸른 배경을 중성 회색으로 조정하고 버튼·상태 표시의 강조색을 다듬었습니다. 확대·해상도 변화에 따라 요약 박스가 내용 높이에 맞춰 늘어나고, 넓은 화면에서는 참가자와 중복 연결 패널의 하단이 정렬됩니다. 필터·검색 변경 시 첫 결과로 이동하고 현황 새로고침 시에는 읽던 위치를 유지합니다.

## 실행과 검증

- [v0.6.2 릴리스](https://github.com/ianlyoo/zoomcheck/releases/tag/v0.6.2)에서 설치 프로그램, portable ZIP과 `SHA256SUMS.txt`를 받습니다.
- ZIP 전체를 새 폴더에 풀고 `ZoomCheck.Backend.exe`를 실행합니다. 기존 프로그램은 먼저 종료합니다. 별도 .NET 설치는 필요 없습니다.
- 기본 DB 경로는 기존과 같은 `%LOCALAPPDATA%\ZoomCheck\data\zoomcheck.db`입니다. 이번 기능은 테이블을 추가하는 방식으로 저장됩니다.
- 자동화 검사 **533개 통과**: .NET 473개 + 대시보드 JavaScript 60개.
- 임시 DB와 가상 명단 8명으로 실제 HTTP 업로드·집계·제외·CSV·복원·검토·연결 지정 및 잘못된 요청의 400/404/409 응답을 확인했습니다.
- 패키지의 Windows EXE를 직접 실행하여 동일한 HTTP 검사를 통과했습니다. 상태 응답과 실행 파일에서 버전 0.6.2를 확인했고, 배포 서버가 전달한 JavaScript 파일이 최종 소스와 일치하는지 바이트 해시로 확인했습니다.
- Chrome에서 제외·복원, 검토 확인·취소, 연결 지정·취소, 직접 입력을 조작했습니다. 밝은/어두운 1280×800 화면과 390×844 화면을 확인했으며 브라우저 오류 로그는 없었습니다. 좁은 화면의 첫 참가자 행은 약 669px 위치로, 이전 점검의 약 842px보다 위에 보입니다.
- GPT-6 Astra 한 명이 프론트엔드 구현 및 저장 로직 검토에 참여했습니다. 검토에서 발견한 재입장·이름 변경 관련 기록 문제를 수정하고 회귀 검사를 추가했습니다.

실제 Zoom 회의와 운영 명단을 이용한 연동 검사는 수행하지 않았습니다. 공개 패키지는 릴레이 주소나 자격증명을 새로 포함하지 않습니다. GitHub Actions에서 검증 후 설치 프로그램과 portable ZIP을 함께 빌드하는 릴리스 절차를 사용합니다.
