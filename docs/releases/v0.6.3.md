# ZoomCheck v0.6.3

릴레이 주소가 설정되지 않은 Windows 앱이 자기 PC에서만 유효한 코드를 만들고, 회의 안 Zoom 앱은 다른 릴레이에서 그 코드를 찾던 문제를 수정했습니다.

## 수정 사항

- 릴레이 주소와 직접 HTTPS 주소가 모두 없으면 코드 생성을 차단하고 설정을 안내합니다. 릴레이 서버에 연결하지 못했을 때도 로컬 코드로 대체하지 않습니다.
- **설정 → Zoom 앱 (Pro) 페어링 → 내 HTTPS 릴레이 주소**에서 주소를 저장할 수 있습니다. 주소는 Windows 사용자 설정 폴더에 저장되어 앱 업데이트 후에도 유지됩니다.
- 설정 화면에서 저장한 주소와 활성화 설정이 이전에 임시로 지정한 환경 변수보다 우선합니다. 설정 화면에서 저장한 적이 없는 PC는 기존 환경 변수를 계속 사용합니다.
- 주소를 저장한 뒤 재시작이 필요하면 코드 생성을 막습니다. 브라우저를 새로고침해도 저장한 주소와 재시작 안내가 유지되며, 이전 주소의 늦은 응답으로 잘못된 코드가 다시 표시되지 않습니다.
- 설정 저장의 성공·실패에서 로딩 표시가 정상 종료되도록 수정했습니다.
- Business API와 명시적으로 설정한 직접 HTTPS 브리지 경로는 유지합니다.

## 적용 방법

1. `ZoomCheck-Setup-x64.exe`로 업데이트합니다. 기존 앱의 **설정 → Windows 앱 업데이트**도 사용할 수 있습니다.
2. 설정에서 **회의 안 ZoomCheck 앱과 같은 릴레이의 루트 주소**를 저장합니다. `/zoom-app/`까지 붙여넣어도 루트 주소로 정리합니다.
3. 브라우저 창뿐 아니라 실행 중인 **ZoomCheck.Backend.exe를 완전히 종료**한 뒤 ZoomCheck를 다시 실행합니다.
4. 이전 코드를 버리고 **새 페어링 코드**를 만들어 회의 안 Zoom 앱에 입력합니다.

주소가 이미 올바른 환경 변수로 설정되어 있다면 업데이트 후 그대로 사용할 수 있습니다. 공개 설치파일에는 개인 릴레이 주소나 자격증명을 포함하지 않습니다. 주소 저장 위치는 `%LOCALAPPDATA%\ZoomCheck\config\appsettings.User.json`입니다.

## 다운로드와 검증

- 설치 파일: `ZoomCheck-Setup-x64.exe`
- 무설치 패키지: `ZoomCheck-portable-win-x64.zip`
- 파일 확인: `SHA256SUMS.txt`

자동화 검사 563개(.NET 495개 + 대시보드 JavaScript 68개)를 통과했습니다. 코드 생성 차단, 릴레이 등록 요청의 코드와 표시 코드 일치, 주소 저장·재시작·기존 설정 우선순위, 화면 상태와 비동기 응답을 검사합니다. 임시 DB로 서버를 실행하여 설정 저장 후 실제 프로세스 재시작과 변경된 컴패니언 주소도 확인했습니다. 릴리스 빌드는 Windows에서 전체 자동화 검사와 패키지 검사를 실행합니다. 실제 Zoom 회의의 계정 권한·네트워크 환경과 설치 후 재시작은 별도 운영 환경 확인이 필요합니다.
