# ZoomCheck v0.7.0

출석 확인을 더 빠르게 하고, 설치와 첫 설정을 줄였습니다. 화면이 한국어·영어·스페인어를 지원하고, 큰 명단에서도 동기화와 화면 갱신이 빨라졌습니다.

## 새 기능

- **회의 현황 복사**: 출석 화면에서 현재 상황을 깔끔한 글로 복사하거나 `.txt`로 저장할 수 있습니다. 전체 인원 중 접속 인원, 미참석자 명단(명단 번호 포함), 중복 접속자(예: `· 2회 접속`)가 들어갑니다. 메신저에 그대로 붙여넣을 수 있습니다.
- **번호순 정렬**: 출석 표를 명단 번호 순서로 정렬할 수 있습니다.
- **다국어 화면**: 한국어, 영어, 스페인어로 전환할 수 있습니다. 영어·스페인어 머리글의 명단 파일도 가져올 수 있습니다.
- **휴대폰 요약 줄**: 휴대폰 화면 위쪽에 `출석 226/300 · 미참석 74`처럼 핵심 숫자를 보여 줍니다.
- **전화번호 검색**: `010-0000-0005`처럼 하이픈을 넣어도, 빼도 같은 사람을 찾습니다.

## 개선 사항

- **명단 가져오기**: 잘못된 파일이나 빈 값은 오류 대신 화면 안에 한국어로 이유를 보여 줍니다. 같은 번호가 여러 번 있으면 `같은 번호 2건 (5번 학생005) · 6, 32행`처럼 위치까지 알려 줍니다.
- **검토 필요**: 실제로 확인이 필요한 모호하거나 충돌하는 항목만 모읍니다. 300명 예시 명단에서 231건이던 목록이 8건으로 줄었습니다.
- **릴레이 주소**: 저장하면 바로 적용되어 앱을 다시 시작할 필요가 없습니다. 연결 확인으로 주소가 맞는지 바로 볼 수 있고, 저장한 주소를 비워서 지울 수도 있습니다.
- **설치**: 설치 화면이 5개에서 3개로, 클릭이 4번에서 2번으로 줄었습니다.
- **동기화 실패 안내**: 메시지 하나만 보여 줍니다. 운영자용 설정 이름은 `자세히 (운영자용)` 안에 들어 있습니다.
- **한글 줄바꿈과 접근성**: 단어 중간에서 줄이 바뀌지 않고, 키보드와 화면 읽기 프로그램으로 쓰기 편해졌습니다.

## 속도

같은 예시 데이터(명단 300명, 그리고 명단 2,000명·접속 1,000명)로 이전 버전과 번갈아 측정했습니다.

| 항목 | 300명 | 2,000명 |
|---|---|---|
| 동기화 1회 처리 | 17.9 → 7.7 ms | 52.3 → 28.9 ms |
| 출석판 불러오기 | 20.5 → 10.6 ms | 122.7 → 40.6 ms |
| 명단 올리기 | 11.5 → 10.4 ms | 69.8 → 51.9 ms |
| 출석 표 그리기 | 3.5 ms 빨라짐 | 69.9 ms 빨라짐 |
| 메모리 | 약 5% 감소 | 약 21% 감소 |

## 업데이트

- `ZoomCheck-Setup-x64.exe`로 덮어 설치하거나, 기존 앱의 **설정 → Windows 앱 업데이트**를 사용합니다.
- 기존 출석 기록, 명단, 수동 매칭, 별칭, 제외 처리, 검토에서 내린 확인·보류 결정은 그대로 유지됩니다. 처음 실행할 때 이전 기록을 새 요약 형식으로 한 번 정리합니다.
- 회의 안 ZoomCheck 앱과 릴레이 사용 방법은 바뀌지 않았습니다.

## 다운로드와 검증

- 설치 파일: `ZoomCheck-Setup-x64.exe`
- 무설치 패키지: `ZoomCheck-portable-win-x64.zip`
- 파일 확인: `SHA256SUMS.txt`

설치 파일은 아직 코드 서명이 없어 Windows가 처음 실행할 때 확인 창을 띄울 수 있습니다.

자동화 검사 635개(.NET 541개 + 대시보드 JavaScript 94개)를 Windows와 Linux에서 통과했습니다. v0.6.3 데이터베이스를 새 버전으로 여는 업그레이드 검사도 포함합니다. 실제 Zoom 계정의 Business API 동기화 성공 경로와 `.xls` 명단 파일은 이번에 별도로 확인하지 않았습니다.
