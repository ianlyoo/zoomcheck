# ZoomCheck v0.6.2

## 주요 변경

- **당일 불참자 제외·복원:** 참가자 상세에서 `오늘 명단에서 제외 (불참)`를 선택하면 출석률·검토·CSV에서 제외됩니다. `제외됨` 목록에서 복원할 수 있고, 원본 명단과 입퇴장 기록은 보존됩니다. 제외는 해당 회의와 PC의 현지 날짜에만 적용됩니다.
- **검토와 명단 연결:** 신원·중복 연결을 각각 확인하거나 보류할 수 있습니다. 미매칭 기기를 명단 인물과 연결하거나 취소할 수 있으며, 재입장·이름 변경 시 과거 연결의 출석 근거를 보존합니다.
- **명확한 현황 표시:** 명단 참석·미매칭 이름·기기 연결의 집계 기준과 CSV 범위를 표시합니다. 실제 참가자 수신 시각을 화면 조회 시각과 구분합니다.
- **직접 입력 개선:** 전체 참가자 목록 적용 전에 확인하고, 중복 줄과 입장·퇴장 처리 결과를 안내합니다.
- **화면 수정:** 기존 배치를 유지하면서 다크모드 배경을 중성 회색으로 조정하고 강조색을 정리했습니다. 확대·해상도 변경 시 요약 문구가 박스 밖으로 넘치던 문제와 참가자·중복 연결 패널 하단 정렬을 수정했습니다.
- **안정성 개선:** 명단 재업로드 시 인물 식별자 보존, 이전 회의의 늦은 응답 차단, 업데이트 설치 파일 검증 상태, OAuth 설정 확인과 webhook 검증을 보완했습니다. CSV 한글 인코딩과 SQLite 네이티브 의존성도 개선했습니다.

## 다운로드

- **일반 설치:** `ZoomCheck-Setup-x64.exe`
- **무설치 실행:** `ZoomCheck-portable-win-x64.zip` 전체를 압축 해제한 뒤 `ZoomCheck.Backend.exe` 실행
- **파일 검증:** `SHA256SUMS.txt`

두 실행 패키지 모두 Windows x64용이며 별도 .NET 설치가 필요 없습니다. 기본 DB 경로는 기존과 같은 `%LOCALAPPDATA%\ZoomCheck\data\zoomcheck.db`입니다. 설치 파일과 ZIP에는 자격증명·DB·명단·출석 데이터가 포함되지 않습니다.

기존 앱의 **설정 → Windows 앱 업데이트**에서도 새 버전을 확인할 수 있습니다. 공개 패키지에는 개인 릴레이 주소가 포함되지 않으며, 기존 연결 설정을 계속 사용합니다.

## 검증

.NET 테스트 473개와 대시보드 JavaScript 테스트 60개로 출석·명단·검토·업데이트 동작을 검증했습니다. 화면 수정은 실제 브라우저에서 확인했습니다. 실제 Zoom 회의 연동과 설치 후 자동 재시작은 별도 환경 확인이 필요합니다.
