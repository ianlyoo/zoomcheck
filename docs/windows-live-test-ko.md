# ZoomCheck Windows 실회의 테스트

이 절차는 공동 호스트 Windows PC에서 Excel 명단과 현재 Zoom 참가자를 안전하게 대조하기 위한 것입니다. ZoomCheck는 참가자 패널에서 읽은 행 수와 Zoom이 표시한 총 참가자 수가 같을 때만 스냅샷을 반영합니다. 일부 행만 읽힌 경우에는 기존 출석 상태를 변경하지 않습니다.

## 준비

1. `ZoomCheck-win-x64.zip`을 Windows PC로 옮겨 압축을 풉니다.
2. Zoom Workplace에서 회의에 공동 호스트로 들어갑니다.
3. **참가자** 패널을 회의 창 오른쪽에 도킹하고 가능한 한 크게 엽니다.
4. 압축을 푼 폴더에서 `ZoomCheck.App.exe`를 실행합니다. 별도 .NET 설치는 필요하지 않습니다.

## 자동 대조

1. Zoom에 표시된 실제 회의 ID를 입력합니다. 회의 ID가 비어 있으면 스캔과 감시가 시작되지 않습니다.
2. 오늘 사용할 `.xlsx` 파일을 선택하고 **Load roster**를 누릅니다. 표시된 명단 인원 수를 Excel과 대조합니다.
3. **Attach participant panel**을 한 번 누릅니다.
4. Zoom의 총 참가자 수와 ZoomCheck의 **Visible names**가 같은지 확인합니다. 다르면 창을 키우거나 아래 수동 백업을 사용합니다.
5. **Scan once**를 누른 뒤 보드의 재실 인원과 Review queue를 확인합니다.
6. 자동 추적이 필요하면 **Start watching**을 누릅니다. 참가자 패널을 닫거나 분리하지 않습니다.
7. 한 명의 퇴장/재입장으로 상태가 각각 한 건만 바뀌는지 확인합니다.
8. 회의 종료 시 **Stop watching**, **Refresh board**, **Export** 순서로 실행합니다.

## 수동 백업

자동 연결이 실패하거나 참가자 수가 맞지 않으면 **Fallback · paste participant list manually**를 펼칩니다. 현재 참가자 전체를 한 줄에 한 명씩 붙여넣고 제출합니다. 자동 경로와 동일한 영속 스냅샷을 이어서 사용하므로 회의 ID를 바꾸지 않아도 됩니다. 빈 줄과 정규화 후 중복되는 이름은 무시됩니다.

수동 제출은 반드시 일부가 아닌 **현재 참가자 전체 명단**이어야 합니다. 일부만 제출하면 빠진 사람은 퇴장으로 처리됩니다.

## 합격 기준

- Excel 명단 인원 수가 앱의 `Roster loaded`와 같다.
- Zoom 현재 참가자 수가 앱의 `Seen in Zoom`과 같다.
- 실제 퇴장/재입장 1회가 각각 이벤트 1건으로 반영된다.
- Review queue의 동명이인, 기기명, 별칭을 사람이 확인할 수 있다.
- CSV의 전체 행 수가 Excel 명단 인원 수와 같고 `Present`/`Left` 상태가 보드와 일치한다.

## 문제가 생기면

- 참가자 수 불일치: 패널을 도킹하고 모든 행이 보이도록 창을 키우거나 수동 백업을 사용합니다.
- 호스트 이름 불일치: Zoom 표시 이름을 Excel 이름과 맞추거나 Review queue에서 alias를 저장합니다.
- 로컬 서비스 시작 실패: 앱을 닫고 다시 열고, 계속 실패하면 압축을 새 폴더에 다시 풉니다.
- Zoom API 401 경고: OAuth 복구 기능의 설정 문제이며 Windows 참가자 패널 대조에는 영향을 주지 않습니다.
